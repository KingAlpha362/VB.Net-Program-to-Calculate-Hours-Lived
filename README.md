# Hours Lived Calculator · Visual Basic

An introductory Windows Forms exercise estimating hours lived from a supplied age.

## ✨ Highlights

- Calculates `age × 365 × 24`.
- Displays the result in a message box.
- Includes screenshots of the original interface.

## 🚀 Getting started

Create a Visual Basic Windows Forms project in Visual Studio. Add `TextBox1` and `Button1` to `Form1`, then incorporate the handler from `Form1.vb`.

## 🗂️ Repository guide

- [Form1.vb](Form1.vb)

## 📝 Project notes

Only the form code and screenshots are included. The approximation ignores leap years and the exact date of birth.
